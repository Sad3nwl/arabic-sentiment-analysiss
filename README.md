# تصنيف المشاعر للمراجعات العربية (Arabic Sentiment Analysis)

مشروع تعلم آلي كلاسيكي لتصنيف مراجعات عربية (كتب/فنادق) إلى ثلاث فئات:
**Positive / Negative / Mixed**.

## البيانات

- `arabic_reviews.csv`: 99,999 مراجعة، متوازنة تماماً بين الفئات الثلاث
  (33,333 لكل فئة). بدون قيم مفقودة أو صفوف مكررة.

## خطوات المشروع

### 1. فهم الداتا والتحقق من جودتها
فحص الشكل العام، الأنواع، القيم المفقودة، التكرارات، وتوازن الفئات.

### 2. تنظيف النص (`data_cleaning.py`)
تنظيف خفيف يناسب طبيعة البيانات: إزالة الروابط، وسوم HTML، والتشكيل، مع
حذف أي صف يصبح فاضياً بعد التنظيف. النتيجة: `arabic_reviews_clean.csv`.

### 3. التحليل الاستكشافي (`Eda02.py`)
- توزيع الفئات وطول النص لكل فئة (رسومات seaborn/matplotlib).
- أكثر الكلمات تكراراً لكل فئة.
- فحص النصوص القصيرة جداً وظاهرة تكرار الحروف (زي "روووعة").
- **أهم ملاحظة:** فئة *Mixed* فيها كثافة عالية من كلمات التضاد
  ("لكن"، "بس"، "ولا")، ما يؤكد إنها فعلاً تمثل تضارب حقيقي بالمشاعر
  وليست فئة عشوائية أو محايدة.

### 4. التقسيم الطبقي (`split_data03.py`)
تقسيم stratified حسب `label_text` لضمان نفس نسبة الفئات (33.3%) بكل جزء:
- Train: 80% (80,000 صف تقريباً)
- Validation: 10%
- Test: 10%

### 5. بناء الموديل الأساسي (`train04.py`)
- تحويل النص إلى متجهات عددية بـ **TF-IDF** (unigrams + bigrams).
- تدريب **Logistic Regression** كخط أساس (`class_weight='balanced'`).
- **النتيجة:** F1-macro = 0.678 على مجموعة الاختبار.

### 6. تحليل الأخطاء
مراجعة يدوية لعينات فئة *Mixed* المصنّفة خطأ، وكشفنا سببين رئيسيين:
- **Label noise محتمل:** بعض العينات المصنّفة *Mixed* كانت في الواقع
  إيجابية أو سلبية بالكامل بدون أي تضارب حقيقي بالمحتوى.
- **قصور TF-IDF في فهم النفي والسياق:** عبارات زي "ليس جيد" تُفهم
  جزئياً كإيجابية بسبب وجود كلمة "جيد"، رغم أن معناها الفعلي سلبي.
- ميل الموديل لتصنيف النصوص الطويلة ذات الكثافة الإيجابية العالية
  كـ *Positive* حتى لو احتوت على انتقاد قصير بعد "لكن".

### 7. تجربة موديلات وتحسينات بديلة
| الموديل | F1-macro (test) | F1 - Mixed |
|---|---|---|
| Logistic Regression (أساسي) | 0.678 | 0.59 |
| LinearSVC | 0.653 | 0.56 |
| Logistic Regression (معالجة نفي + tuning) | 0.680 | 0.59 |
| Ensemble (LR + SVM + Random Forest) | 0.681 | 0.59 |

التحسينات المجرَّبة: دمج كلمات النفي مع الكلمة التالية لها كوحدة واحدة
(`ليس_جيد`)، `sublinear_tf`، وضبط معامل الانتظام `C` عبر `GridSearchCV`.

### 8. القرار النهائي
كل المحاولات استقرت حول **F1-macro ≈ 0.68**، ما يؤكد الوصول لسقف طبيعي
لهذه المقاربة (TF-IDF + تعلم آلي كلاسيكي) على هذه البيانات — القيد أساسي
وبنيوي (عدم فهم السياق والنفي)، وليس نتيجة نقص بالتجريب.

**الموديل المُعتمد:** Logistic Regression المحسّن — أبسط من الـ Ensemble
وبنفس الأداء تقريباً (0.680 مقابل 0.681).

## أهم الدروس المستفادة

- توازن الفئات من البداية وفّر جهد كبير (بدون حاجة لـ oversampling).
- الفحص اليدوي للأخطاء (error analysis) أهم بكتير من تجربة موديلات
  عشوائية — هو اللي كشف السبب الحقيقي لضعف الأداء على فئة *Mixed*.
- في حد واقعي لأداء موديلات "كيس الكلمات" (bag-of-words) على فهم
  السياق والنفي والتضارب بالمشاعر، وتخطيه بشكل حقيقي بيحتاج نماذج
  تفهم السياق (زي AraBERT) بدل تمثيل TF-IDF.
